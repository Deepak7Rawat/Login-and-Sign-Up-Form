# Login and Sign Up Form

A simple front-end authentication UI built with HTML and CSS. This project contains a login page and a sign-up page with a modern gradient design, clean form layout, and navigation between the two screens.

## Features

- Responsive login form
- Sign-up form with user details fields
- Gradient-based UI styling
- Link between login and sign-up pages
- Pure HTML and CSS implementation

## Project Structure

```text
Login-and-Sign-Up-Form/
├── form.html        # Login page
├── Signup.html      # Sign-up page
├── README.md        # Project documentation
```

## Screens

- Login screen: `form.html`
- Registration screen: `Signup.html`

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Deepak7Rawat/Login-and-Sign-Up-Form.git
   ```
2. Open the project folder in your browser.
3. Double-click `form.html` to view the login page, or open `Signup.html` to view the sign-up page.

You can also use a VS Code live preview or any browser extension to run the pages locally.
