# 🚀 Login and Sign Up Form

A clean and modern front-end authentication UI built with HTML and CSS. This project includes a login page and a sign-up page with a polished gradient design, responsive layout, and smooth navigation between both screens.

## 📌 About the Project

This project is a simple front-end login and registration interface designed for learning and practice. It focuses on building user-friendly forms, attractive UI styling, and responsive page structure using only core web technologies.

The goal is to create a visually appealing authentication experience while keeping the code easy to understand and beginner-friendly.

## ✨ Features

- Responsive login form
- Sign-up form with user details fields
- Modern gradient-based design
- Easy navigation between login and sign-up screens
- Clean and minimal HTML/CSS layout
- Beginner-friendly project structure

## 🛠️ Tech Stack

- HTML5
- CSS3
- VS Code / Browser Preview

## 📂 Project Structure

```text
Login-and-Sign-Up-Form/
├── form.html         # Login page
├── Signup.html       # Sign-up page
├── README.md         # Project documentation
└── assets/           # Optional assets (if added later)
```

## ⚙️ How It Works

The project consists of two pages:

- `form.html` displays the login form
- `Signup.html` displays the registration form

Both pages are styled using CSS to create a modern and consistent look. The design uses soft gradients, card-like containers, and spacing to improve readability and user experience.

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/Deepak7Rawat/Login-and-Sign-Up-Form.git
```

2. Open the project folder in your browser.

3. Open either:
   - `form.html` to view the login page
   - `Signup.html` to view the sign-up page

You can also use VS Code Live Server or any browser extension for local preview.

## 💻 Usage

- Use the login form to simulate a user sign-in page.
- Use the sign-up page to collect user registration details.
- Customize colors, spacing, and layout to match your own branding.
- Expand the project later with form validation, JavaScript interactivity, or backend authentication.
